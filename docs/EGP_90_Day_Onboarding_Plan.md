# ESYASOFT GET PROGRAM — 90-DAY ONBOARDING PLAN

> **90 Days. 5 Phases. One Development Journey.**
>
> A proposed practical onboarding framework for the Esyasoft Graduate Engineer Trainee (GET) Program.

**Status:** Sample / proposed 90-day plan for website integration  
**Purpose:** L&D program proposal and digital onboarding prototype  
**Structure:** ORIENT → DISCOVER → BUILD → SPECIALIZE → CONTRIBUTE

---

# 1. PROGRAM PHILOSOPHY

The objective of the 90-day GET program is not simply to complete training sessions.

It is to move a graduate from:

**NEW JOINER → DOMAIN-AWARE LEARNER → CAPABLE BUILDER → SPECIALIZED TRAINEE → CONTRIBUTOR**

The proposed learning model is:

## 10% LEARN → 20% INTERACT → 70% APPLY

Every major topic should move through:

**UNDERSTAND → TRY → SOLVE → REVIEW → APPLY**

### 10% — LEARN

Structured instruction through:

- Trainer-led sessions
- Expert / SME sessions
- Workshops
- Guided reading
- Demonstrations
- Short technical modules

### 20% — INTERACT

Learning through:

- Mentors
- SMEs
- Peer discussions
- Team activities
- Q&A
- Teach-backs
- Reviews
- Cross-functional conversations

### 70% — APPLY

Learning through:

- Hands-on labs
- Case studies
- Problem solving
- Team challenges
- Technical exercises
- Mini-projects
- Specialization work
- Capstone project
- Demonstrations

The exact balance can vary by topic. The principle is that instruction should lead to application.

---

# 2. 90-DAY STRUCTURE

| Phase | Days | Primary Objective | Major Outcome |
|---|---:|---|---|
| **01 — ORIENT** | 1–5 | Understand Esyasoft, the program and how to operate as a GET | Personal learning roadmap + company/context understanding |
| **02 — DISCOVER** | 6–25 | Understand the energy domain, Esyasoft solutions and professional ways of working | Domain map + end-to-end solution understanding |
| **03 — BUILD** | 26–55 | Build a strong common technical foundation | Working technical mini-project |
| **04 — SPECIALIZE** | 56–80 | Develop role-specific capability | Track-specific case study / prototype |
| **05 — CONTRIBUTE** | 81–90 | Apply learning, collaborate and demonstrate capability | Final team solution + presentation + individual development plan |

---

### KNOWLEDGE

# 13. FINAL PROGRAM PRINCIPLE

> **Don't just train new joiners.**
>
> **Help them understand something, try something, solve something, build something, explain something and demonstrate something.**

The goal of the 90-day program is not:

**90 days of sessions.**

It is:

**90 days of progressive capability building.**

**ORIENT → DISCOVER → BUILD → SPECIALIZE → CONTRIBUTE**

**10% LEARN → 20% INTERACT → 70% APPLY**

**UNDERSTAND → TRY → SOLVE → REVIEW → APPLY**

By the end of the journey, the GET should have moved from:

> **"I am new here."**

to:

> **"I understand where I am, what we do, what I can contribute, and what I need to learn next."**
